# Portfolio Form

Docker環境で構築したPHPお問い合わせフォームです。

## 使用技術

- PHP
- MySQL
- nginx
- Docker
- Linux
- Git / GitHub

---

## 機能

- お問い合わせフォーム
- データベース保存
- 一覧表示
- 編集機能
- 削除機能
- バリデーション

---

## ディレクトリ構成

```text
portfolio-form/
├ docker-compose.yml
├ nginx/
├ php/
├ src/

## アクセス方法

Docker起動後、ブラウザで以下にアクセスしてください。

```text
http://サーバIPアドレス:8080
